# 原生播放器核心原型

这是 Godot/GDScript 的原生播放器原型，用于验证读取引擎编译后的 `story.json`、独立 UI 对象、分支和跳转；初步支持框体绘制、文字换行、层级变换和 UI 位移插值。不包含完整界面、Spine 插件、音频、原版动画或导出模板，文字富文本及逐字时序也尚未完整实现，因此不是可交付播放器，也不会由现有构建按钮调用。

在工作区根目录运行 `npm run test:native-core` 可使用本机 Godot 在临时副本中执行与编译器之间的协议测试及 Windows 图形后端的非空画面检查。可用 `GODOT_EXECUTABLE` 指定 Godot 4 可执行文件。模型来自 Spine 4.1；接入对应原生运行时前须确认版本、平台支持与许可证。
