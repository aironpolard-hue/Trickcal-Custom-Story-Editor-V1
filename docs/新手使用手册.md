# Trickcal 剧情制作引擎：新手使用手册

网页完整版位于 `docs/manual/index.html`。双击引擎根目录的 `打开使用手册.bat`，或在启动器、编辑器点击“使用手册”即可查看；提供分类目录、全文搜索、代码复制、三个完整案例和命令速查。网页可直接离线打开。

本手册对应当前源码版。示例项目是 `projects/雨夜的末班车`，剧本位于项目的 `story/main.trickcal`，其中的中文注释解释每段代码。`#` 开头的行不会显示在剧情里。

## 启动和预览

1. 双击工作区根目录的 `启动引擎.bat`；它启动源码版。源码更新后，先保存当前内容，再关闭并重新打开引擎。
2. 在启动器打开“雨夜的末班车”。编辑代码后按 `Ctrl+S` 保存，或点击“检查”查看错误。
3. 点击“运行预览”从头播放。文字正在逐字显示时，第一次点击画面可立即显示全文，再点击推进剧情。
4. 在左侧点击预设，右侧会显示对话或动作效果；点击“重新播放”可再次查看动画。动作预览使用示意图片，实际演出会作用于剧本指定的角色或图片。
5. 舞台面板可选择段落并点击“载入当前段预览”。分支场景应从开头逐条选择验证，跳转预览不是完整存档。

编辑器会在你查看代码和问题面板时暂停两个隐藏预览画布的绘制，以减少大型剧本编辑时的卡顿；预览运行时的剧情时间线、逐字显示、角色动作和音频事件仍会继续推进。切换回“预览”或“预设详情”后会自动恢复绘制。该优化只针对编辑器内嵌预览，不改变独立播放器的行为。

## 项目和素材

- `trickcal.project.json`：项目设置和入口文件。
- `story/main.trickcal`：剧情脚本。
- `assets/`：图片、音频及 Spine 素材；使用系统文件管理器将素材放进此目录。
- `presets/`：项目的预设文件。
- `backup/20261104-原剧本与旧预设/`：本次改写前的剧本及预设备份。
- `.preview/`：预览生成文件；`build/`：构建输出及旧输出归档。

新项目默认要求素材先声明再使用。路径相对于项目目录，用英文双引号和正斜杠：

```trickcal
image ner_avatar = "assets/herohead/ner.png"
define ner = Spine("assets/spine/standing/ner", name="尼尔", avatar=ner_avatar, avatarBg="#9fc766")
image station = "assets/bg/elf_city_night.png"
define audio.rain = "assets/audio/silent.wav"
scene bg station
show ner at left pose Idle_1
audio play rain loop
ner normal "雨还没有停。"
audio stop rain fadeOut 1s
narration "雨渐渐停了。"
```

`ner`、`station` 和 `rain` 是自行指定的名称，大小写要一致。Spine 文件夹需要同名 `.skel.bytes`、`.atlas.txt` 及贴图，动作名须存在于模型中。教程的音频是静音占位文件。音频命令在下一段可播放剧情开始时执行。

角色的 `show` 和 `spawn` 可以使用 `at left` 等站位，或用 `at 960,540` 指定坐标；`face` 只能是 `1` 或 `-1`，`scale` 须大于零，`alpha` 范围为 0 到 1。参数拼写错误、缺少数值或数值越界会在“问题”面板标出对应行；并行块内的 `show` 使用相同规则。图片 `alpha` 同样须在 0 到 1 之间。

检查和构建时会读取 atlas，检查它引用的每张贴图是否存在；缺失时“问题”面板会在声明行提示具体贴图。使用素材导入按钮时，所有贴图必须位于所选 Spine 文件夹中，导入会一起复制；手写声明可以引用项目 `assets` 内的共享贴图。这个检查不验证骨骼文件是否损坏或 Spine 版本是否兼容，仍需实际预览确认。

有名字的框显示台词开头角色的 `name`；独白框显示该角色指定的 `avatar` 和 `avatarBg`。头像必须先用 `image` 声明，再写到 `Spine(...)` 里；没有设置头像的新式声明不会自动匹配内置角色。旧式项目仍保留兼容行为。也可只覆盖一条台词：

```trickcal
ner clear "雨似乎更大了。" name "尼尔" avatar ner_avatar avatarBg "#75a659"
```

`name` 是显示名，`avatar` 是已声明的图片名称，`avatarBg` 是头像背后的六位颜色。行内设置只影响本句，优先于角色默认值；底色也可在独白框预设后写 `avatarBg "#75a659"`，行内设置优先。

音频参数可以按需组合，例如 `audio play rain volume 0.5 times 2 fadeIn 500ms fadeOut 1s`：音量范围是 0 到 1，`times 2` 表示总共播放两次，`fadeIn` 是开始时淡入，播放命令中的 `fadeOut` 是最后一次播放接近结尾时淡出。`loop` 表示循环播放，与 `times` 和播放命令的 `fadeOut` 不能同时使用；停止循环可用 `audio stop rain fadeOut 1s`，此处的淡出从停止命令执行时开始。时间可以写秒（`1s`）或毫秒（`500ms`）。同名音频再次播放会替换前一次；在 `parallel` 内使用时按事件时间执行。浏览器或手机可能限制自动播放，用户下一次与画面交互时会尝试恢复尚未停止的音频；不同设备的限制可能不同。

本引擎的语法借鉴了 Ren'Py，但不是 Ren'Py，也不执行 Python；`Spine(...)` 是本引擎扩展。`scene bg black` 是内置黑屏写法。

## 遮罩转场

```trickcal
preset 转场·黑场 hold 0.8
transition
transition circle hold 1.2
```

转场在当前舞台上播放遮罩，结束后自动继续；它本身不会切换背景。预设有黑场、圆形、推镜和色条，也可用 `kind` 覆盖样式，`hold` 覆盖秒数（至少 0.2 秒）。`transition` 语句直接指定的样式和时长优先于预设。这些是引擎自绘效果，不是直接播放原游戏转场。

## 开场与地点预设

```trickcal
preset 章节开场 uiScale 0.95 cinema false
opening 1 "雨夜的末班车" hold 0 bg black
preset 地点标识 uiX 40 uiOpacity 0.9
location "中央车站" hold 1
```

开场可选择 `章节开场` 或 `章节开场·无电影边框`；开场与地点预设都支持 `uiX`、`uiY`、`uiScale`、`uiRot` 和 `uiOpacity`。开场另支持 `cinema true` 或 `cinema false`；如果 `opening` 自己写了 `cinema on/off`，以该语句为准。`hold` 仍须写在对应的剧情语句中。它们播放的是引擎根据提取数据重放的动画，不是直接运行 Unity 动画。

## 对话和预设

新闻框和全屏文字同样可以逐条调整：

```trickcal
preset 新闻框·主播 fontSize 52 shadowX 16 shadowY 12 shadowColor "#222222" shadowAlpha 0.3 entryDuration 0.8
news anchor "列车因暴雨晚点。"
preset 新闻框·简报 textColor "#012060"
news summary "请留意站台广播。"
preset 全屏文字 fontSize 64 textColor "#ffffff"
fullscreen "末班车终于来了。"
```

`news anchor` 和 `news summary` 决定主播或简报样式；预设不改写语句本身的样式。两类新闻框和全屏文字支持整体变换、文字偏移、字号、颜色和打字速度，新闻框额外支持阴影。新闻框使用提取素材，并由引擎重放 `Dialogue_NewsText_Entry` 的入场缩放曲线，不是直接运行 Unity 动画；`entryDuration` 是本次入场时长，单位为秒，须大于零，默认 0.5 秒。`enter none` 可关闭入场动画，关闭时入场时长不产生效果。全屏文字也由引擎绘制。

```trickcal
preset 漫画对话气泡
ner manga "末班车快到了。"
preset 漫画对话气泡 bubbleWidth 800 shadowX 18 shadowY 20 shadowColor "#3b2852" shadowAlpha 0.45
ner manga "这一次只调整这一句。"
preset 紫色内心气泡
ner manga "希望雨早点停。"
ner think "这是圆点尾巴的思考气泡。"
ner normal "我们再等一会儿。"
```

`preset` 只影响下一条兼容的对话，不会自动更改对话模式。可以在名称后依次写 `参数 值`，只覆盖本次对话，原预设文件不变。`shadowX` 向右为正、`shadowY` 向下为正，`shadowColor` 使用双引号中的六位颜色，`shadowAlpha` 为 0 到 1；目前用于漫画气泡、普通/云朵/爆炸对话框、独白框及拟声框，不适用于所有剧情模式。可设置的其他参数包括 `bubbleWidth`、`bubbleMinHeight`、`bubbleMaxHeight`、`bubblePaddingY`、`textWidth`、`fontSize`、`typeSpeed`、`textColor`、`uiX`、`uiY`、`uiScale`、`uiRot`、`uiOpacity`、`textOffsetX`、`textOffsetY`、`enter`、`exit`、`tail`、`purple`；具体效果取决于对话模式。

预设面板中的“预览模式”只决定预览使用哪种对话模式，不会改写剧本里的 `normal`、`manga` 等模式。点击“插入到光标”会将面板中可编辑的参数值一起写入；参数只用于接下来的语句，不会修改预设文件。

漫画箭头尾巴可写 `tail bl`（左下）、`tail br`（右下）、`tail tl`（左上）、`tail tr`（右上），也可写中文方向，例如 `preset 漫画对话气泡 tail 右上`，或在台词末尾写 `tail tr`。`think` 的圆点尾巴使用自身固定样式，不受箭头方向设置影响。连续漫画气泡默认逐个播放退场与入场，`exit none` 或 `enter none` 可分别关闭对应动画。

台词末尾的 `hold 0` 表示自动播放时文字显示完成后不额外停留，例如 `ner manga "快看。" hold 0`。有尚未结束的 `parallel` 时间线时，自动播放仍会等待时间线完成；手动播放需要点击推进。`hold` 的单位是秒，不能为负数。

独白框的连续对话可以这样写：

```trickcal
ner clear "雨还没有停。"
erpin clearRe "我们再等等。"
ner clearRe "好。" enter none
```

紧接 `clear` 或另一条 `clearRe` 的 `clearRe` 会保留框体，并重新播放头像和名字的入场；`enter none` 关闭本句入场。若前面没有独白框，或本句用 `after` 延时，播放器会重新显示完整框体。名字、头像、底色和其他单句预设参数仍按新台词更新。

漫画和思考气泡可用 `overflow` 设置长文字处理方式：`grow` 随文字增长到 `bubbleMaxHeight`，再跟随打字滚动；`shrink` 固定为 `bubbleMinHeight` 并缩小字号，最低 12，仍放不下的部分会裁切；`scroll` 固定高度并跟随打字滚动；`clip` 固定高度，只显示开头能容纳的内容。`grow` 和 `scroll` 出现滚动后，可在文字区域使用滚轮或触摸拖动查看已显示的文字；拖回底部后继续自动跟随。

```trickcal
preset 漫画对话气泡 overflow scroll bubbleMinHeight 320 bubblePaddingY 60
ner manga "较长的文字会在这个气泡中滚动显示。"
```

紫色内心漫画气泡使用 `manga`，是箭头尾巴；`think` 使用圆点尾巴。`normal` 是普通对话框，`cloud` 是云朵框，`clear` 是独白框。选中预设后可在右侧编辑并预览；点击保存会修改该预设文件，所有没有单独覆盖参数的引用会使用新值。

预设名称后缀“有名字”或“无名字”控制名字区域；例如 `preset 云朵对话框·有名字` 配合 `ner cloud "文字"`，`preset 爆炸框·无名字` 配合 `ner blast "文字"`。预设不自动更改台词模式。

不同样式依据已提取的素材和动画数据由引擎重放，并非直接运行原游戏的 Unity 动画；部分效果仍有近似。

旁白框、拟声框和动画字幕也可应用预设：

```trickcal
preset 旁白框 fontSize 60
narration "雨渐渐停了。"
preset 拟声框 shadowX 20 shadowY 30 shadowColor "#333333" shadowAlpha 0.6
sfx "汽笛——" at 960,470
preset 动画字幕 textColor "#ffffff"
ner anime "列车到了。"
```

拟声框使用提取的入场曲线，但当前框体是 Canvas 近似形状，不是原版 SDF 着色器。

普通对话框内的逐字效果也可以单次调整，例如 `preset 普通打字机 speed 0.06 punctuationPause 0.2 typeSpeed 1`。`speed` 是基础逐字间隔的秒数，`typeSpeed` 是速度倍率，`punctuationPause` 是逗号、句号、问号等标点后额外等待的秒数，句末不会额外延长等待。它作用于下一句普通对话，不是独立打字机对象；富文本 `<pause=0.3>` 的停顿会与标点停顿相加，`<speed=80ms>` 则使用标签指定的逐字间隔。

## 动作、分支

```trickcal
parallel:
  say ner manga "我走过去看看。"
  move ner x by 100 in 0.8s ease InOutSine

choice "去哪里？"
  "站台" -> platform
  "候车厅" -> hall
label platform:
  narration "她走向站台。"
  jump finish
label hall:
  narration "她留在候车厅。"
label finish:
  fullscreen "雨停了。"
  end
```

`parallel`（也可以写成中文别名 `同时:`）中的 `say` 和 `move` 同时播放；`by` 是相对位移。选项必须缩进，箭头后写目标 `label`，`jump` 可让路线汇合。更多用法及参数见教程剧本里的逐段注释。

气泡和文字属于对应的对话句子。紫色内心漫画气泡使用箭头尾巴，紫色思考气泡使用圆点尾巴；单句参数覆盖不会修改预设文件。

### 变量与条件

```trickcal
default trust = 0
set trust += 1
if trust >= 1:
  narration "她愿意相信这段广播。"
else:
  narration "她仍然有所怀疑。"

choice "是否继续等待？"
  "继续" -> wait_more
  "离开" -> leave if trust >= 2
```

先用 `default` 声明数字、布尔值或字符串初值；`set` 支持 `=` 和数值复合赋值；`if` 支持比较、`and`、`or`、`not`、括号及基础算术。可以在 choice 选项末尾添加 `if trust >= 2`；条件不满足时该选项不可点击。变量会随实际剧情路线保存；编辑器跳转预览只恢复已访问路线的变量状态，未访问段落从默认初值开始。当前版本没有跨重启存档功能。

`parallel` 目前并非任意语句的通用并发容器。它支持一条角色台词、`narration`、`cloud`、`sfx`、`news` 或 `fullscreen`，一次性 Spine 表情 `oneshot`，以及角色或图片的 `move`、角色的 `anim` 和 `skin`、`camera`、背景 `scene bg`、画面 `effect`、`shader`、`audio play` 和 `audio stop`、`wait`。角色台词可以直接写 `ner normal "你好"`；旧的 `say ner normal "你好"` 仍可使用。对话前可写 `preset`，它按照脚本书写顺序作用于下一条兼容对话，不是一个定时事件。其他上述语句可放入 `after 0.5s:` 或 `after 500ms:` 延时执行，嵌套延时会相加；每个并行块仍只允许一条对话。动作预设可写为 `move ner preset 跑入`，拉伸预设会使缩放保持在目标值，除非后续再次改变。`choice`、`jump`、`label`、`end` 等控制流语句不能并发执行，编译器会明确报错。

着色器也可以延时切换，`shader reset` 会关闭当前着色器：

```trickcal
同时:
  shader heat 0.35
  after 800ms:
    shader reset
  ner normal "热浪效果与台词同时开始。"
```

内置着色器可用 `heat`、`dream`、`gray`、`glitch`、`wave`。自定义片元着色器必须放在项目 `assets/shaders/` 目录并使用 `.frag` 文件；检查阶段会验证路径和文件是否存在。设备不支持 WebGL 或 shader 编译失败时，播放器会显示效果警告，但不会停止剧情。

同一对象的同一属性存在多条绝对值移动时，已经开始的动作中，开始时间较晚的覆盖较早的；同时开始则以脚本中后写的为准。`by` 相对移动会叠加。正常播放时提前翻页，角色、图片、镜头、画面效果、背景混合和着色器会保留当时已发生的状态，尚未触发的事件不会补做；经条件、选项、`jump` 或转场继续后，所经路线明确写出的设置仍会生效。背景渐变停在当时的混合画面，直到后续剧情再次改变背景。编辑器跳转到未访问段落、复杂绑定和动作交错仍有边界，不能视为完整存档恢复。旧构建需要重新构建才能使用新行为。

`parallel` 也支持延时 `show` 和 `hide` 角色：

```trickcal
parallel:
  after 500ms:
    show erpin at right face -1
  after 750ms:
    hide ner
  erpin normal "她终于赶到了。"
```

这类舞台事件会在当前段落的时间线上执行，并影响下一段的舞台快照；图片也支持并行显示和隐藏，控制流语句仍需在并行块外使用。

如果角色还未登场或已经被隐藏，不能在该时间点播放其 `anim` 或设置 `skin`；编译器会标出对应语句。模型加载期间已经发生的动作设置会在模型可用后应用，若角色在加载前已被隐藏则不会重新出现。

图片也可以使用相同的时间线语法：

```trickcal
image station = "assets/bg/elf_city_night.png"
parallel:
  after 200ms:
    show image station as poster at 960,540 scale 0.2 alpha 0.7
  after 300ms:
    move poster x 960 -> 1160 in 400ms ease Linear
  after 700ms:
    hide poster
  wait 1s
```

图片显示支持 `at`、`scale`、`sx`、`sy`、`rot`、`alpha`、`brightness` 和 `z`；素材仍须先用 `image` 声明。

可以用同一个舞台对象名切换到另一张已声明的图片，例如 `show image station as poster at 960,540` 之后写 `show image hall as poster at 960,540`。同一个对象名和内置头像同名也不会引用到内置头像；新图片尚未加载完成时暂不显示该图片。

角色和图片也可以在时间线上绑定：

```trickcal
parallel:
  after 500ms:
    bind poster to ner offset 80,0
  after 800ms:
    unbind poster at 100,200
  wait 1s
```

`bind` 的偏移是父对象本地坐标；并行块中的 `unbind` 必须写 `at` 坐标，用它作为解绑后的屏幕位置。绑定关系会影响后续舞台快照，不能形成循环。

绑定期间，图片仍可独立使用 `move poster alpha 1 -> 0.5 in 1s` 和 `move poster brightness 1 -> 1.3 in 1s`。当前绑定对象的位置、旋转和缩放由父级及绑定偏移计算；不要依赖同时对已绑定子级写这些属性的 `move` 来改变绑定偏移，需要调整时先解绑或重新绑定。

`parallel` 内的登场、隐藏、绑定、角色动作和移动会先按实际开始时间排列，即使 `after 500ms:` 写在 `after 200ms:` 前面也一样。同一时刻按代码先后顺序执行：应先显示对象，再绑定或移动它。对象隐藏后重新显示会使用新一次 `show` 的状态，不会继承此前的移动轨道。

一次性 Spine 表情也可以与台词同时播放：

```trickcal
define emoticon = Spine("assets/spine/emoticon")
parallel:
  after 100ms:
    oneshot spine emoticon anim Idea at 960,520 scale 0.8 alpha 1
  ner normal "小心！"
```

先声明素材；`anim` 写素材内的动画名，`at` 是画面坐标，`scale` 是正数，`alpha` 为 0 到 1，还可设置 `rot`、`face 1`／`face -1` 和 `skin`。同一块可以有多个表情，提前翻页会停止当前表情并取消未触发的表情。静态预览按所选时间定位表情；素材加载失败时请检查开发者控制台。动画名未找到时目前会回退到素材中的第一个动画。

角色和图片可以先设为透明，再延迟淡入；透明不会把对象从舞台移除。`hide` 才会移除对象。

```trickcal
show ner at left alpha 0
parallel:
  after 0.5s:
    move ner alpha 0 -> 1 in 1s ease Linear
```

动作预设可以在名称后追加只对本次生效的参数，例如 `move ner preset 跑入 from right duration 0.4 ease Linear`，或 `move ner preset 拉伸 scaleX 1.1 scaleY 0.9 duration 0.5`。`duration` 单位为秒，`from` 可选 `left` / `right`，缩放值是当前大小的倍率。两个预设是引擎提供的通用动作，不是声称完整还原的原游戏角色动作。

图片和 Spine 角色也能分别动画横纵缩放：`move ner scaleX 1 -> 1.3 in 0.5s`、`move poster scaleY 1 -> 0.8 in 0.5s`。起点、终点是缩放倍率；`scaleX` / `sx` 控制宽度，`scaleY` / `sy` 控制高度。

提前翻到下一句会取消尚未到时间的音频事件，已经开始的音频继续播放；编辑器静态跳转预览不触发音频，选择重新播放才会从头执行。移动在提前翻页时，下一句仍使用编译得到的最终位置，不保证从中途位置无缝继续。

镜头、角色动作与皮肤的后续舞台快照按本并行块各事件的时间顺序计算；即使提前翻页，下一句也会使用这些语句的最终结果。预览跳到本句的指定时间时会恢复已经到达的镜头与角色状态，但不会播放音频。

背景和画面效果也按事件时间切换，提前翻页后下一句使用并行块的最终设置。例如 `effect tint "#ff0000" 0.25` 中颜色必须用英文双引号，透明度为 0 到 1；`effect reset` 清除画面效果。背景默认即时变化，也可以在并行块中交叉淡化：

```trickcal
parallel:
  scene bg hall in 500ms ease Linear
  wait 500ms
```

背景渐变的 `scene` 必须放在 `parallel` 或 `同时` 块中；支持秒和毫秒，缓动名称沿用动作缓动。

在 `parallel` 中可以渐变画面效果，例如 `effect brightness 1 -> 0.5 in 1s ease Linear`。可渐变属性为 `brightness`、`contrast`、`saturation`、`blur` 和 `tintAlpha`；数值不可为负，`tintAlpha` 在 0 到 1 之间。渐变 `tintAlpha` 前需先设置 `effect tint` 的颜色。效果设置与渐变按开始时间排序，同一时刻按书写顺序执行；渐变中的数值超出有效范围时会被限制。当前不支持 `by` 相对渐变。

编辑器右侧“时间轴”会列出移动、镜头和效果渐变，以及背景、音频、角色和即时设置事件。它目前用于查看和预览，轨道尚不能直接拖动编辑。

舞台对象使用左上角为原点的坐标：向右 X 增大、向下 Y 增大。摄像机可用 `camera target 960,540` 设置视野中心，坐标与舞台对象一致；例如舞台点 `1280,540` 会显示在屏幕中心。也可在 `parallel` 内动画视野中心：`camera targetX 960 -> 1180 in 1s`、`camera targetY 540 -> 600 in 1s`。原有 `camera x/y` 仍表示画面平移量，用于兼容旧剧本；新的坐标控制请用 `target` / `targetX` / `targetY`。

镜头缩放与旋转也可平滑变化，例如 `camera zoom 1 -> 1.2 in 1s ease Linear`、`camera rotate 0 -> 10 in 1s`。缩放起点和终点须大于零；`targetX`、`targetY`、`x`、`y`、`rotate` 可用 `by`，缩放暂不支持 `by`。同一属性的多条镜头设置按开始时间处理，时间相同时按书写顺序处理；后开始的设置会覆盖此前的绝对值，相对值叠加在此前结果上。镜头跟随角色时，画面位置由跟随及其 offset 决定。

```trickcal
parallel:
  move ner x by 100 in 1s ease Linear
  after 0.5s:
    say ner normal "先听听雨声。"
    audio play rain loop
    anim ner Surprise_1 fade 0.25
    camera zoom 1.1
```

延时期间对话框尚未出现，点击不会提前显示台词；开始后可以像普通对话一样点击完成打字、再次点击翻页。自动播放会等到台词的停留时间和本并行块的动作、音频触发时间都到达，手动翻页则可以提前结束本段。

`wait 1.5s` 或 `wait 1500ms` 会隐藏对话框、保留舞台并等待指定时间，然后自动继续；等待期间点击不会跳过。没有台词的 `parallel` 也会自动等待其中的移动、音频触发和 `wait` 都结束。`after` 内的 `wait` 从该延时到达时开始计算。动作、镜头和画面效果的 `in` 时长及其 `after` 参数也可使用毫秒，如 `move ner x by 100 in 500ms after 250ms`。

```trickcal
wait 0.5s
parallel:
  move ner x by 100 in 1s ease Linear
  after 0.5s:
    wait 1s
ner normal "走到了。"
```

角色和图片可分别设置不透明度和亮度，亮度 `0` 为黑色，`1` 为原亮度，大于 `1` 为提亮。场景的 `effect brightness` 和对象亮度会叠加：

```trickcal
show ner at left alpha 0.8 brightness 0.5
spawn image station as poster at 1400,400 scale 0.2 alpha 0.8 brightness 1.2
parallel:
  say ner normal "灯亮起来了。"
  move ner brightness 0.5 -> 1 in 1s ease Linear
  move poster alpha 0.8 -> 0.3 in 1s ease Linear
```

## 排查

- **预览没有变化**：保存剧本、停止并重新运行预览；源码更改需要重启引擎。已构建的程序需要重新构建。
- **找不到素材或预设**：检查声明名称大小写、路径及文件是否存在，并查看“问题”中的行号。
- **卡顿**：可停止不需要的播放预览。后台检查和预览分辨率已有优化，但大型项目及复杂模型仍可能产生负载。

## 构建和代码

当前 Windows 构建使用 Electron，Android 使用 Capacitor/WebView；它们能生成应用，但**不属于原生渲染运行时**。原生发布方案尚未确定。Android 默认生成测试用 debug APK；正式签名和已知限制见《DSL 与运行时现状》。

代码入口：`compiler/trickcal.js` 负责编译，`runtime/app.js` 负责播放绘制，`editor/app.js` 负责编辑器界面，`main.js` 负责项目读写和构建。使用或发布游戏素材前，请自行确认授权。
