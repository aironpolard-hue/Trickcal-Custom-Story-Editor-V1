## 清理措施

- 在协议和 README 中添加 AI 辅助制作声明。
- 添加根目录 `.gitignore`，排除依赖、构建、预览、缓存、日志、本机配置及签名文件。
- 将历史发行包、剧情构建、Android 中间产物、已安装依赖、临时预览与截图、扫描临时文件和日志移至工作区外的本地清理归档。执行环境拒绝了递归删除，因此采用可恢复的移出方式，归档并未永久删除。
- 将原始 Android 签名文件及旧签名配置单独移至工作区外的本地私有目录，避免丢失已有签名身份；这些文件不属于源码交付内容。
- 清理时引擎仍在运行，Electron 依赖目录被占用；该目录暂留本地并由 `.gitignore` 排除，关闭引擎后方可移出。
- 保留剧情源码、教程素材、项目清单和历史源码备份，没有将它们作为构建产物处理。

若旧发行包或构建目录曾对外公开，应将其中的签名材料视为已暴露，重新评估签名使用和更新安排；仅从当前工作区移出文件不能撤回已经分发的副本。
